# 日本語・数字抽出ツール

テキストファイルから、日本語（ひらがな、カタカナ、漢字）と数字（半角全角）以外の文字（アルファベット、記号など）を削除するツールです。

## 機能

*   **日本語と数字の抽出**: 以下の文字のみを残し、それ以外を削除します。
    *   ひらがな
    *   カタカナ
    *   漢字
    *   数字（半角 `0-9` および 全角 `０-９`）
*   **改行の保持**: ファイルの構造を崩さないよう、改行コードはデフォルトで保持します（チェックボックスで変更可能）。
*   **GUI操作**: わかりやすい画面でファイルの選択と保存ができます。
*   **UTF-8 / Shift-JIS対応**: 日本語テキストファイルで一般的なエンコーディングに対応しています。

## 使い方

1. `src/text_cleaner/main.py` を実行してツールを起動します。
2. 「ファイルを選択...」ボタンをクリックし、処理したいテキストファイルを選びます。
3. 「処理を開始する」ボタンをクリックします。
4. 保存先を指定すると、自動的に処理が実行され、結果が保存されます。

## 開発者向け情報

*   **Logic**: `src/text_cleaner/logic.py` に正規表現を用いた抽出ロジックがあります。
*   **GUI**: `src/text_cleaner/gui.py` にTkinterを用いたGUIの実装があります。
