# Google Maps 店舗情報収集スクリプト (安全重視版)

Googleマップから店舗情報（店舗名、住所、電話番号、URL）を、人間の操作を模したペースで安全に収集するためのツールです。
Playwrightを使用し、ランダムな遅延やスクロール操作を行うことで、ブロックのリスクを最小限に抑えています。

## 推奨環境
- Python 3.10以上
- Windows / Mac / Linux
- **VPNの使用を強く推奨** (NordVPNのObfuscatedサーバーなど)

## インストール方法

1. 必要なライブラリをインストールします。
   ```bash
   pip install -r requirements.txt
   ```

2. Playwrightのブラウザをインストールします。
   ```bash
   playwright install chromium
   ```

## 使い方

1. **キーワードリストの作成**
   収集したい検索キーワード（例：「新宿区 美容室」）を1行ずつ記述したテキストファイル（`.txt`）またはCSVファイル（`.csv`）を用意します。

2. **ツールの起動**
   以下のコマンドを実行してGUIを立ち上げます。
   ```bash
   python src/google_maps_scraper/main.py
   ```
   ※ リポジトリのルートディレクトリから実行してください。

3. **GUIでの操作**
   - **入力ファイル**: 「参照」ボタンから、用意したキーワードリストを選択します。
   - **安全設定**:
     - 最小/最大遅延: 1件ごとの待機時間を設定します（デフォルト8〜15秒推奨）。
     - 1日上限: 安全のため、1日の収集件数上限を設定できます。
   - **開始**: 「開始 (Start)」ボタンを押すと収集が始まります。

4. **CAPTCHA（「ロボットではありません」）が出た場合**
   - ログに「⚠️ CAPTCHA検出！」と表示され、処理が一時停止します。
   - ブラウザ画面でCAPTCHAを手動で解除してください。
   - 解除後、GUIの「再開 (Resume)」ボタンを押すと、処理が継続されます。

## 出力ファイル

`output` フォルダ内に生成されます。
- `結果_YYYYMMDD_HHMM.xlsx`: 収集結果（店舗名、住所、電話番号、URL）
  - ※ 店舗名と住所の組み合わせで自動的に重複除去されます。
- `error_log.txt`: エラーが発生したキーワードの記録
- `progress.json`: 進捗状況の保存用（次回起動時に続きから再開するため）

## 設定ファイル (config.json)

高度な設定は `src/google_maps_scraper/config.json` を直接編集することで変更可能です。
- `headless`: `true` にするとブラウザを非表示で実行します（デバッグ時は `false` 推奨）。
- `selectors`: GoogleマップのHTML構造が変更された場合、ここを修正します。

## 注意事項

- **安全第一**: 収集スピードを上げすぎるとGoogleにブロックされる可能性があります。デフォルトの設定（8〜15秒待機）を守ることをお勧めします。
- **良識ある利用**: サーバーに過度な負荷をかけないようご注意ください。
