# Google Maps Scraper Agent Guidelines

1. **Safety First**: All scraping logic MUST implement random delays (minimum 8-15 seconds) and human-like scrolling.
2. **Language**: All User Interface text, comments, and logs MUST be in Japanese (日本語).
3. **Respect Limits**: Do not bypass daily limits or hammer the server.
4. **GUI**: Use Tkinter with a professional, polite design.
