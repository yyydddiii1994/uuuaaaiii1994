# Google Search Scraper

Google検索結果を自動でスクレイピングし、広告や不要な要素を除外してCSVに保存するツールです。
Tkinterを使用したGUI版です。

## 技術解説＆注意点（kotetsu354メモ）

### `div.g` というクラスについて
Googleの検索結果ページ（SERP）の構造は複雑ですが、長年**「純粋な検索結果」**は `<div class="g">` というタグに入っていることが多いです。これを使うことで、広告や地図をある程度自動で弾けます。
※ただし、Googleは頻繁にコードを変えるので、動かなくなったら `div.g` の部分を見直す必要があります。

### BAN対策（超重要）
スクリプト内の `time.sleep`（待機時間）は絶対に削らないでください。
Googleはロボット的な動きに敏感です。もし大量のキーワード（50件以上など）をやる場合は、スマホのテザリングを使って機内モードON/OFFでIPアドレスを変えるという裏技も併用すると最強です。

### 目視チェックの役割
このスクリプトは「下書き」を作るためのものです。
生成されたCSVをざっと見て、明らかに無関係なサイトが混じっていないか（特に「知恵袋」や「NAVERまとめ的な古いサイト」など）を確認する時間は確保してください。それでも手作業の1/10の時間で終わります。

## 使い方

1. 必要なライブラリをインストールします。
   ```bash
   pip install -r requirements.txt
   ```

2. ツールを起動します。
   ```bash
   python main.py
   ```
   ※ `main.py` を実行するとGUIが立ち上がります。

3. **GUI操作**:
   - **出力フォルダ**: 参照ボタンから保存先を選べます。
   - **取得件数**: デフォルトは20件です。
   - **Headlessモード**: チェックを入れるとブラウザを表示せずに実行します（CAPTCHA対応が不要な場合）。
     - **重要**: CAPTCHA（「私はロボットではありません」）が出現する可能性がある場合は、チェックを外して（デフォルト）実行し、手動でクリックして助け舟を出せるようにしてください。
   - **検索キーワード**: 1行に1つのキーワードを入力してください。
   - **開始**: 処理を開始します。
   - **停止**: 実行中の処理を中断します（現在のキーワード処理後に停止）。

## トラブルシューティング

### 起動しない場合
`main.py` を実行した際、依存ライブラリの不足などで起動に失敗した場合は、自動的に「起動エラー」ウィンドウが表示され、エラー内容（ログ）が表示されます。その内容を確認して対応してください。
